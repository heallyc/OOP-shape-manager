# OOP-shape-manager
C++ console-based application that allows users to dynamically create, manage, and manipulate geometric shapes using object-oriented programming principles.

**This project emphasizes core object-oriented programming concepts such as:**
Inheritance and polymorphism
Dynamic memory management
Encapsulation through class design
Modular code organization using separate header and source files
Purpose

The goal of this project is to demonstrate strong understanding of C++ OOP design patterns while building a practical, interactive command-line application for managing geometric objects.

## Key Features
- Add multiple shape types
- Store and manage shapes dynamically using a ShapeManager class
- Display all stored shapes with formatted output
- Uniformly scale all shapes by a user-defined factor
- Polymorphic design using a common Shape interface
- Robust input validation for user interaction
